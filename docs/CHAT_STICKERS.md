# Crazy Desert chat stickers

The 20 PNG stickers in `src/assets/chat-stickers` were generated for this project on September 21, 2026 with OpenAI image generation using the owner's screenshot of the existing Crazy Desert sandstone mascot as a style reference. The prompt specified an irregular layered rock character in a transparent 5×4 atlas; separate images were cropped and resized to 256×256. No third-party character names or logos were supplied. The original set of 13 mascot PNG files was unavailable in this working copy; if those files are provided, replace the generated versions with the approved originals where appropriate.

The sticker picker attaches one PNG to the existing chat image field. The normal server image validation, encrypted storage and access rules also apply to stickers. The PNGs themselves are public app assets; private messages containing them remain in the protected chat service.
